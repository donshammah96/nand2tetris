# Nand2Tetris: Build a Modern Computer from First Principles

![Status](https://img.shields.io/badge/status-not%20started-lightgrey) ![Weeks](https://img.shields.io/badge/weeks-4-blue) ![Hours](https://img.shields.io/badge/hours-~80-blue)

Build a working computer from NAND gates up through the assembler, virtual machine, a high-level language compiler, and an operating system.

## Topics

- Boolean logic and combinational chips
- Sequential logic and memory
- Machine language and computer architecture
- Assembler, VM translator, and compiler
- Operating system basics

## Working method

1. Watch or read the unit, and take notes in `notes/`.
2. Attempt every problem before checking any solution.
3. Commit each completed problem set with a descriptive message.
4. Write a short summary in `notes/` at the end of each unit.
5. Update the status badge and progress checklist at each milestone.
